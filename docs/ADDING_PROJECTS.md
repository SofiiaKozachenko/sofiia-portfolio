# Як додати новий кейс до портфоліо

## Найпростіше
1. Опублікуй кейс на Behance у профілі `sofiiakozachenko`.
2. Автоматична перевірка Behance запускається щодня. Якщо публічний профіль повертає новий проєкт та авторство підтверджується, сайт сам імпортує оригінальну послідовність зображень, обкладинку й доступні відеовставки.

## Гарантований ручний варіант (без програмування)
1. Відкрий файл [content/sources.json](https://github.com/SofiiaKozachenko/sofiia-portfolio/edit/main/content/sources.json) і натисни Edit.
2. У масив `additional` додай об'єкт із короткою латинською назвою URL та посиланням Behance:

```json
{
  "profile": "https://www.behance.net/sofiiakozachenko",
  "additional": [
    {
      "slug": "my-new-project",
      "title": "My New Project",
      "category": "branding",
      "url": "https://www.behance.net/gallery/123456789/My-New-Project"
    }
  ]
}
```
3. Замінити приклад на реальне посилання та назву; збережи Commit changes.
4. GitHub Actions автоматично імпортує кейс, додасть його до каруселі та опублікує оновлення, якщо перевірки успішні.

**Доступні категорії:** `branding`, `digital`, `packaging`. Категорія не ділить карусель на групи; потрібна тільки для метаданих.
**Якість:** сайт зберігає оригінальні зображення й створює WebP-копії для швидкого показу; натискання відкриває оригінал.
**Відео:** вставка Vimeo відтворюється автоматично без звуку, коли з'являється в зоні видимості. Деякі браузерні налаштування можуть забороняти autoplay.
**Відвідувачам нічого робити не потрібно** — після публікації всі кейси відкриваються просто на сайті.
